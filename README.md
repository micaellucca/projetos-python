# Projetos básicos em Python

Pequenos programas de terminal que fiz para praticar lógica de programação em Python.

## Projetos

| Arquivo | O que faz | O que pratica |
|---|---|---|
| `geradornumeros.py` | Jogo de adivinhação: o programa sorteia um número de 1 a 50 e você tem 5 tentativas, com dicas de "maior" ou "menor" | `random`, `while`, `try/except`, validação de entrada |
| `verificadorpalindromo.py` | Diz se uma palavra ou frase é um palíndromo (igual de trás para frente) | Manipulação de strings e fatiamento (`[::-1]`) |

## Como rodar

```bash
python3 geradornumeros.py
python3 verificadorpalindromo.py
```

## Tecnologias

Python 3 · Git
